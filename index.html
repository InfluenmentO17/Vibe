C'est quoi le Vibeathon ?

Le Vibeathon n'est pas un hackathon classique. C'est un format nouvelle génération lié à la tendance du vibe coding — coder avec l'IA, les prompts et les bons outils plutôt qu'uniquement avec du code pur. Tu arrives avec une idée, tu repars avec un produit.
